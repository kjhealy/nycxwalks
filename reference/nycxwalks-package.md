# nycxwalks: Geographic Crosswalks for New York City Boundaries

Crosswalk tables that show how fifteen New York City administrative and
statistical geographies overlap. The geographies include community
districts, police precincts, council districts, Neighborhood Tabulation
Areas, and ZIP code tabulation areas. For each pair of overlapping
features, the tables give the intersection area and the share of each
feature that the intersection covers. The package also includes the
boundaries that were used to compute the tables. The nycbuildxwalks
package built the tables. nycbuildxwalks is an R port of the Python tool
by Nathan Storey at MODA-NYC
(<https://github.com/MODA-NYC/nyc-geography-crosswalks>). That tool
builds on earlier work by BetaNYC
(<https://github.com/BetaNYC/nyc-boundaries>).
